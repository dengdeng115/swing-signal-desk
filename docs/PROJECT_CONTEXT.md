# 项目上下文

## 目标

把指定 Discord 美股波段频道的消息完整留档，解析成可审查的候选交易指令，结合实时行情做有限资金的前向模拟交易，并在网页展示持仓、资金利用率、信号延迟、滑点与收益复盘。

## 当前边界

- 当前是个人使用的模拟交易工作台，不连接真实券商，不自动下真实订单。
- GitHub Pages 网址是静态演示；长期在线的数据采集、AI 和数据库需要独立后端服务器。
- 本机 PostgreSQL 13.21 已创建项目数据库 `swing_signal_desk`、最小权限应用角色和 Navicat 只读角色；密码不得写入仓库或聊天。
- 本地 `.env` 已设置 `DATABASE_URL`，后端默认使用 PostgreSQL。移除该值才会回退到重启即清空的内存演示模式。
- 已回补目标频道最近一个月 629 条原始消息，并生成可审计的信号级交易腿；严格自动统计与组合模拟收益必须保持分离。
- 本地网页通过后端显示真实月度聚合与原文；公开 GitHub Pages 只显示隐私降级状态，不嵌入付费频道内容。
- 长桥只读报价已接入网页行情卡，必须展示盘前/盘后或常规盘标签及时间；不得用当前行情改写历史成交价。

## 核心决策

1. Discord 只允许官方 Bot；保留 create/update/delete 原始事件。
2. 确定性规则优先，AI 仅在规则不够明确时给候选结果。
3. AI 必须返回 JSON Schema 约束的结构；输出仍视为不可信输入。
4. 所有候选先经过资金与风险规则；即使通过，也只允许人工确认后的模拟成交。
5. 收益同时记录信号价与模拟成交价，不把理论最高收益当成可执行收益。
6. 所有关键行为写审计记录，规则、解析器和模型必须带版本。

## 默认风控

- 初始资金：1,000,000 USD
- 总资金利用率上限：70%
- 单一股票权重上限：20%
- 强制现金垫：30%
- 规则解析置信度阈值：85%
- 信号最大允许时延：120 秒

这些是可配置默认值，不代表投资建议。改动时必须记录生效时间和版本。

## 下一次继续工作的入口

1. 先阅读根目录 `AGENTS.md` 和本文件。
2. 查看 `docs/CHANGELOG.md` 的最后一条和 `docs/ROADMAP.md` 未完成项。
3. 运行 `npm ci`、`npm test`。
4. 检查 `git status` 和两个远端，避免覆盖用户修改。
5. 数据库变更从 `db/migrations/` 追加新迁移，禁止重写已经上线的迁移。
6. 运行 `npm run db:verify`，确认应用角色非超级用户、迁移完整、Navicat 角色只读。
