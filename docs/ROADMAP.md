# 路线图

- [x] 内存演示仓库
- [x] 中文规则解析器与基础测试
- [x] 资金/集中度/现金垫/时延风控

## 下一阶段

- [ ] 由服务器管理员用最小权限邀请链接把 `duobot` 加入目标服务器和频道
- [ ] 用户本人把 Bot Token 写入本机 `.env`，再启用并验证真实消息采集
- [ ] 在 Navicat 创建项目专用数据库和最小权限用户
- [ ] 用 1–2 周真实频道历史消息建立标注样本
- [ ] 冻结规则 v1，统计准确率、漏报率、误报率
- [ ] 接入长桥实时行情并验证行情权限、时区和延迟
- [ ] 完成模拟订单、部分成交、费用、滑点和持仓账本计算
- [ ] 把在线后端部署到长期运行环境，连接 PostgreSQL
- [ ] 网页切换到真实 API/SSE，同时保留明确的演示标识
- [ ] 增加登录、只读/确认者角色和审计导出

## 上线门槛

- 消息编辑/删除不丢失；断线可检测并告警。
- 所有收益能追溯到原始消息、行情时点、成交假设和费用。
- 模糊消息不生成自动模拟成交。
- 任何密钥均未进入 Git 历史、浏览器包或日志。
- 经过前向模拟观察后再讨论更高自动化级别。
