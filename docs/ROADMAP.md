## 上线门槛

- 消息编辑/删除不丢失；断线可检测并告警。
- 所有收益能追溯到原始消息、行情时点、成交假设和费用。
- 模糊消息不生成自动模拟成交。
- 任何密钥均未进入 Git 历史、浏览器包或日志。
- 经过前向模拟观察后再讨论更高自动化级别。
